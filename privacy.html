Privacy Policy — Job Outreach Assistant

Last updated: 2026-10-07

Job Outreach Assistant is a private tool used only by its owner. It has no other users.

Data accessed

  • Gmail: the tool sends job-application emails that the owner has approved, and reads replies in those email threads so they can be tracked.
  • Google Sheets: the tool writes application status to a spreadsheet the owner controls.

Storage and sharing

Data is processed and stored only on the owner's own computer. It is not sold, not shared with third parties, and not used for advertising.

The tool's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions.
